# 测试记录

测试日期：2026-10-09 至 2026-10-10。设备：K2P / MT7621，Padavan 4.4.198.9-100_20220804，sing-box mini 1.12.13，ShellCrash 1.9.4release。

## 实机测试

| 项目 | 结果 |
| --- | --- |
| 订阅下载与应用 | ShellCrash 原生获取、实际面板解析器生成配置、校验和加载通过 |
| 节点数量 | 101 AnyTLS、45 SS + HTTP 混淆，共 146 节点 |
| 旧节点检测 | 3 个 SS + HTTP 节点 HTTPS 检测成功，984、361、359 ms |
| DNS | Google 返回 Fake IP；百度、OpenAI、STUN、Apple、小米返回真实地址 |
| 分流 | 国内域名与国内 IP 直连，Google 经所选节点 |
| 服务与重启 | 服务启停、Storage 保存及整机重启恢复通过 |
| 开机与守护 | 开机启动开启，ShellCrash 原生每分钟守护运行，主动停止不被恢复 |
| 失败保护 | 无效订阅保留服务；内核准备失败不停止旧代理 |
| 后台集成 | 菜单和登录集成通过；原“科学上网”入口保留 |
| 备份与恢复 | BusyBox 单一工作目录备份、已有安装恢复与首次安装失败撤销通过 |

45 个原始 SSR 节点采用 origin/http_simple，服务商按客户端标识提供兼容 Shadowsocks 格式；不是任意 SSR 都能在 sing-box 上运行。

转换列表在 K2P 实机读取通过。共用下载脚本在 AX5 验证第一项服务预检失败时不发送订阅，第二、第三项分别完成转换和加载；未在 K2P 重复向第三方发送私人订阅。

## 自动检查

66 项 Python 检查和 5 项实际解析器协议检查通过，覆盖安装、备份回退、启动守护、规则路径、内存保护、订阅兼容与恢复内核准备。脚本语法和源码差异格式检查通过。

## 测试边界

安装助手尚未在另一台干净设备上完成全新安装。其他 Padavan 分支、自定义启动钩子、长期高负载及任意旧部署迁移需单独验证。

正式版工具更新在实机验证了同版不替换；新版本替换及失败回退使用离线测试。K2P 保留固件内置 ZeroTier，本项目不升级该组件。

最近一次 K2P 管理页被另一客户端占用，未强制退出已有会话；订阅更新通过实际后台流程验证，页面预览使用示例数据。
