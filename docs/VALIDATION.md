## v1.0.1 订阅与协议复验（2026-10-10）

K2P 实际调用 ShellCrash 下载订阅，再用面板解析器生成候选配置并应用。导入 146 节点：101 AnyTLS、45 Shadowsocks + HTTP 混淆，服务接口确认数量与类型一致。上述 45 节点的原始链接为 origin/http_simple SSR，服务商按客户端标识提供兼容 Shadowsocks 格式。不是所有 SSR 都可转换为 SS。

转换列表读取实机 ShellCrash 三个服务；同一适配脚本在 AX5 上验证第一项预检失败时不发送订阅，第二和第三项分别完成转换及加载。K2P 使用相同下载适配脚本；未在 K2P 重复向第三方发送私人订阅。预检与故障轮询同时经过离线测试。

66 项 Python 检查通过，包含下载内核失败不停止当前服务；新增实际解析器的 5 项协议测试，覆盖兼容 SSR、不可兼容 SSR、Base64、无效链接。K2P 当前使用 sing-box，不提供原生 SSR 支持。启动、守护、内存保护及备份回退保留。

更新后实测 3 个兼容 SS + HTTP 节点的 HTTPS 延迟为 984、361、359 ms。6 项 DNS 检查通过：Google 返回 Fake IP，百度、OpenAI、STUN、Apple、小米返回真实地址。服务仍运行，开机启动开启，ShellCrash 每分钟守护生效，异常恢复计数为 0。
